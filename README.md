# Amigo Secreto

## Descripción
Este programa permite realizar un juego de Amigo Secreto, donde los usuarios pueden agregar los nombres de sus amigos, y luego hacer un sorteo aleatorio para asignar a cada persona un "amigo secreto". Los resultados del sorteo se muestran en la interfaz.

## Características
- Agregar Amigos: Los usuarios pueden ingresar los nombres de sus amigos.
- Mostrar la Lista de Amigos: Los amigos agregados se muestran dinámicamente en una lista.
- Sorteo Aleatorio: Los nombres son sorteados aleatoriamente, asignando un "amigo secreto" a cada persona.
 Interfaz Intuitiva: La aplicación tiene una interfaz simple con botones para agregar amigos y sortear el amigo secreto.
- Actualización en Tiempo Real: La lista de amigos y los resultados del sorteo se actualizan en tiempo real en la interfaz.

## Tecnologías Utilizadas
- HTML: Para la estructura de la página web.
- CSS: Para el estilo visual (se puede agregar para mejorar la apariencia).
- JavaScript: Para la lógica y la interacción dinámica en la página.

## Instalación
Para usar este programa, solo necesitas un navegador web moderno. Aquí están los pasos para poner en marcha el programa localmente:

# Descargar los Archivos:
Descarga o clona este repositorio en tu máquina local.

## Abrir el Proyecto:
Abre el archivo index.html en tu navegador preferido.

## Ejecutar el Proyecto:
El programa no requiere un servidor backend. Simplemente abre el archivo HTML directamente en tu navegador para empezar a agregar amigos y realizar sorteos.

## Uso
## Agregar Amigos:
En la sección "Digite el nombre de sus amigos", escribe el nombre de un amigo en el campo de texto.
Haz clic en el botón "Añadir" para agregarlo a la lista de amigos.
- Ver Lista de Amigos:
Los amigos que agregues aparecerán en la lista que se muestra debajo del campo de entrada.
- Sortear Amigo Secreto:
Haz clic en el botón "Sortear amigo" para seleccionar aleatoriamente un amigo secreto de la lista.
El nombre del amigo sorteado se mostrará en la sección de resultados.
- Repetir el Sorteo:
Puedes agregar más amigos y hacer otro sorteo tantas veces como desees.
